# ffew-fightlog

An [Alliance Auth](https://gitlab.com/allianceauth/allianceauth) plugin for FFEW. Members upload their EVE Online combat logs, and the plugin turns them into fights everyone can search: timelines, per-side damage/rep/ewar tables, and side detection for post-mortems.
