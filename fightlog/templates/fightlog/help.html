{% translate "The one setting that matters: your overview ship label" %}

Damage lines in your gamelog always name pilots as Pilot[CORP](Ship). Every other line — reps, cap transfers, neuts, jams and tackle — names them with your overview ship label. If your label shows only the ship type, those lines read remote shield boosted by Loki, and nobody can tell which Loki it was.

  • Any label that includes the pilot name works. The client's stock label does (Sabre <ALLY>[CORP] Pilot), so if you never changed it, you're fine.
  • The label lives in the overview settings (Overview → settings → Ships / label options). It is stored per EVE account and shared by that account's characters, and importing an overview profile can replace it.
  • If your alliance shares an overview profile, the easiest fix is a profile whose ship label includes pilot, corp and alliance.
{% translate "Where are my gamelogs?" %}
  • Windows: Documents\EVE\logs\Gamelogs
  • macOS: ~/Documents/EVE/logs/Gamelogs
  • Linux (Steam / Proton): ~/.steam/steam/steamapps/compatdata/8500/pfx/drive_c/users/steamuser/Documents/EVE/logs/Gamelogs

Each character session writes YYYYMMDD_HHMMSS_<characterID>.txt. Files without a character ID are empty character-select sessions and are skipped. You can drop the whole folder on the upload page: only sessions in the chosen date range that contain combat are sent. Only English client logs are understood for now.

{% translate "Reading a fight" %}
  • Grey cells are partial: that pilot didn't upload a log, so you only see what touched someone who did. Logged pilots' rows are complete.
  • Hit % is only shown for turrets, drones and fighters. Missiles, smartbombs and bombs never miss, so they show n/a.
  • Unknown <ship> rows are ship-only labels that couldn't be matched to a pilot. A curator can attribute them.
  • Likely friendly: a group that only exchanged smartbomb hits with us in both directions. It stays on Unknown until killmails, an ally setting or a curator places it — smartbombs hit friend and foe alike, so they're never evidence.
  • System: from zKillboard killmails first, then from a log's last system line if no wormhole could have been crossed since. Wormhole jumps are never logged, so J-space fights without killmails show J-space, system unknown.
  • Clock: logs are aligned against each other before duplicates are removed. Offsets above 2 seconds are highlighted.
  • Toggling a log only changes your view and the link you share. Excluding a log for everyone is recorded in the fight's history.
